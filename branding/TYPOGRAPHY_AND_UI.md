# Typography and UI Direction

## Typography

Use a combination of:

- premium serif for headings
- clean sans-serif for interface labels
- monospace for Prompt Engine and technical readouts

## UI materials

- deep maroon base
- navy metallic surfaces
- old gold trim
- render-teal data lines
- violet secondary accents
- dark glass panels

## Motion language

- slow metallic shimmer
- prompt typing cursor
- render progress bars
- old gold reveal pulse
- teal hover outlines

## Interaction style

The UI should feel controlled and deliberate, not noisy.
