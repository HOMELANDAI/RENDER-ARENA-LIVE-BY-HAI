# Expedition Engine

The Expedition Engine structures every Homeland Safari journey.

## Inputs

- target artifact
- canon importance
- hidden location
- terrain chain
- weather arc
- animal encounters
- mythic implication
- phase count
- prompt count
- final reveal
- map prompt
- YouTube package
- thumbnail prompt
- frame deck

## Output

A continuity-locked visual sequence that can become:

- short film
- YouTube episode
- social reel
- XR gallery
- Homeland Hunt clue package
