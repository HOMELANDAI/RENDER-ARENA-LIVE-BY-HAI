# Homeland Hunt Bridge

## Relationship

Homeland Safari and Homeland Hunt share treasure-seeking DNA.

## Homeland Safari role

Safari creates:

- mythology
- artifacts
- maps
- ruins
- expedition lore
- clue imagery
- character history
- visual canon

## Homeland Hunt role

Hunt turns that mythology into:

- playable discovery
- clues
- maps
- timed search
- interactive movement
- rewards
- community participation

## Strategic loop

```text
Safari creates legend
-> Hunt makes it playable
-> Players discover clues
-> Discoveries feed new Safari arcs
```

## Recommendation

Use Render Arena to publicly create Safari lore and select which artifacts or maps become Homeland Hunt assets.
