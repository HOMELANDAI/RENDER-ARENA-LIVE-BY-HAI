# Production Workflow

## Pre-production

- choose weekly theme
- choose 3-4 prompt candidates
- choose approved colorways
- prepare OBS scenes
- prepare Maestro/Twitch polls
- test render pipeline

## Live production

1. Open show
2. Introduce theme
3. Display Colorway Prompt Engine
4. Run colorway vote
5. Lock prompt
6. Render first generation
7. Compare variants
8. Refine based on structured input
9. Vote final
10. Send winner to Render Vault

## Post-production

- export full replay
- cut YouTube episode
- cut Shorts
- publish Render Vault entry
- create social post
- update prompt archive
- prepare next episode
