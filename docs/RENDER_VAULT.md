# Render Vault

## Purpose

The Render Vault is the permanent public archive of Render Arena outputs.

## Each render entry stores

- title
- episode number
- platform source
- final image
- prompt
- prompt version
- colorway
- vote count
- vote percentage
- creator notes
- remix history
- status
- XR candidacy
- mint candidacy

## Render statuses

- Draft
- Finalist
- Community Favorite
- Archived
- Featured
- XR Candidate
- Mint Candidate

## Website features

- filter by colorway
- filter by episode
- filter by platform
- filter by theme
- filter by XR-ready
- compare variants
- open prompt breakdown
- send to gallery

## Strategic value

The Render Vault turns livestream output into a permanent asset library.
