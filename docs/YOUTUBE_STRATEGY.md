# YouTube Strategy

## YouTube role

YouTube should preserve the best version of each Render Arena episode and transform live sessions into evergreen content.

## Content types

- full episode replay
- 8-12 minute edit
- 60-second Shorts
- prompt breakdown
- colorway explanation
- RTX workflow segment
- Render Vault showcase
- Homeland Safari scene documentary

## Why YouTube works

Render Arena naturally produces educational and cinematic material. Viewers can search for prompt design, AI art workflows, studio setup, and colorway systems.

## Recommended title formats

- We Built a Cinematic AI Scene Live
- Prompt Battle: Carbon Slice vs Jacq Supreme
- How HAI Colorways Change AI Images
- RTX-Powered AI Rendering for Live Shows
- From Prompt to Render Vault
