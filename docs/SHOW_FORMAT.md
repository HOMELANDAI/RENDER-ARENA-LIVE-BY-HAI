# Show Format

## Recommended runtime

30 to 45 minutes per live episode.

## Weekly rhythm

Three episodes per week:

1. Prompt Discovery
2. Prompt Build and Render
3. Final Reveal and Archive

## Episode flow

1. Opening and theme reveal
2. HAI colorway selection
3. Prompt Engine construction
4. Render queue activation
5. First generation reaction
6. Viewer-guided refinement
7. Final side-by-side comparison
8. Audience vote
9. Render Vault selection
10. Next episode tease

## Host roles

### Host A: Creative Director

- explains theme
- evaluates composition
- frames the story
- interacts with audience

### Host B: Prompt Engineer / Operator

- manages prompt terminal
- controls colorway inputs
- initiates renders
- compares variants

## Watchability rule

Avoid long dead time. When renders process, fill the wait with:

- prompt analysis
- colorway explanation
- viewer poll
- RTX status commentary
- previous render comparison
