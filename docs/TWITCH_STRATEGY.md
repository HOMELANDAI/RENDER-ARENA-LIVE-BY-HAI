# Twitch Strategy

## Twitch role

Twitch should be treated as the live pulse of Render Arena.

## Strengths

- real-time audience interaction
- chat culture
- clipability
- high reaction value
- strong fit for head-to-head render battles

## Recommended Twitch segments

- Prompt or Pass
- Colorway Vote
- Render Reaction
- Variant Showdown
- Final Render Poll
- Chat Suggestion Filter

## Important constraints

Do not let chat fully control the show. Viewer input should be structured through approved colorways, controlled modifiers, and host-curated prompt options.

## Watchability keys

- frequent visual changes
- clear countdowns
- active render progress
- visible voting
- host commentary during render waits
- fast transitions from prompt to image
