# UI Spec: Render Vault

## Purpose

A premium gallery archive for final Render Arena outputs.

## Grid card fields

- image
- title
- episode
- colorway
- vote percentage
- status
- platform source

## Detail page fields

- full render
- prompt
- colorway
- variant history
- voting result
- creator notes
- remix pathway
- XR candidate flag
- mint candidate flag

## Filters

- colorway
- episode
- theme
- platform
- most voted
- latest
- XR-ready
- Homeland Safari
- festivals
- sports
- studio

## Visual direction

Deep maroon background, navy metallic panels, old gold frames.
