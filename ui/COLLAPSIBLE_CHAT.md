# UI Spec: Collapsible Chat

## Purpose

A site-wide HAI creative assistant.

## Position

Bottom-right floating widget.

## Collapsed state

- HAI icon
- label: Ask HAI
- old gold glow

## Expanded state

- chat history
- quick actions
- prompt suggestion input
- colorway explanation
- latest live status

## Quick actions

- Explain this colorway
- Suggest a prompt
- What's live now?
- Show latest render
- How do I vote?
- Open Render Vault
- Explore Homeland Safari

## Tone

Creative assistant, not generic customer support.
