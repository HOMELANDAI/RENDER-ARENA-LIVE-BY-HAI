# Contributing

Render Arena Live by HAI is currently a concept and specification repository.

## Contribution types

Useful contributions include:

- UI/UX mockups
- frontend prototypes
- broadcast overlay designs
- OBS workflow notes
- Firebase/Supabase realtime architecture
- prompt engine logic
- RTX workflow tests
- XR scene prototypes
- Render Vault metadata models
- Homeland Safari scene development

## Working principles

1. Preserve HAI brand identity.
2. Keep interaction structured, not chaotic.
3. Treat every render as a potential scene or world.
4. Prioritize watchability over technical showing-off.
5. Build in phases.

## Pull request checklist

- Does the change support Render Arena's core show format?
- Does it preserve HomelandAI / HAI terminology?
- Does it improve clarity for developers, designers, or production collaborators?
- Does it avoid overpromising unfinished technology?
