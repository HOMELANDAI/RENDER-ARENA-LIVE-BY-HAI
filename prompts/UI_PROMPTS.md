# UI Prompts

## Arena Floor

The hero screen is a live head-to-head render battle. The screen splits into two artist panels with an electric VS divider. Each panel shows artist handle and assigned HAI colorway constraint. The main canvas shows artwork resolving in real time. Progress bars advance in render-teal and violet. Vote counts and split percentage bars update live. Bottom strip holds two vote buttons and a gold reveal pulse indicator. Near-black palette, render-teal, electric blue, esports HUD for an art arena.

## Colorway Prompt Engine

The pre-round setup screen is half gallery, half terminal. Left panel is the HAI Colorway Selector with four stacked cards: Carbon Slice Supreme, HAI Jacq Supreme, Sage Variant, Vice Edition. Right panel is terminal-style prompt builder with blinking teal cursor and mono-font flags: --colorway, --style, --palette, --mood, --constraint. A Colorway DNA Alignment meter scores prompt coherence. LOCK PROMPT writes to Firestore. Bottom NVIDIA RTX GPU Load bar fills green through teal to heat-orange. Cold, dark, monospace, HAI-branded render-farm technical aesthetic.
